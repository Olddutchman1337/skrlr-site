Security · second focus

How tool-using agents fail when someone pushes back.

I study agents with inboxes, browsers, files, and tools — the same surfaces that make them useful also make them attackable. The work runs in isolated sandboxes with benign canaries, not live data.

Multi-turn social engineering

How I test

Simulate — mock inboxes, chat, files, and tools, fully isolated.

Attack — automated adversarial and insider-threat scenarios against the agent under study.

Observe — canary tokens and tool-call monitors record exactly when a line is crossed.

Publish — reproducible benchmarks, harnesses, and write-ups intended for open release.
