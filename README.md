# Skrlr

Landing site for [skrlr.com](https://skrlr.com) — Skrlr, an AI safety & security lab building an automated, sandboxed agentic red-teaming and insider-threat simulation platform for AI agents. Units: Skrlr Security (the platform), Skrlr Games (AI-first adaptive games, a live testbed for agent behavior) and Skrlr Media.

Static single page (`index.html`, inline CSS, no build step) served by GitHub Pages from `main` / root with custom domain `skrlr.com` (see `CNAME`).
